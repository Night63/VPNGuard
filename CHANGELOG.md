# История версий

## v2.3
- Окно сворачивается в трей через 10 секунд после запуска приложения и через 5 секунд после перезапуска (после восстановления VPN).
- При обрыве VPN окно открывается поверх всех окон и показывается уведомление в трее.
- Версия программы показывается в заголовках окон.
- Разделы настроек переименованы: «Ваш VPN» и «Ваше приложение».
- В путях можно использовать переменные Windows (`%LOCALAPPDATA%`, `%APPDATA%`).
- В ключевые слова адаптера по умолчанию добавлены `browbox` и `sing-tun` (адаптер Browsec).
- Подробный README.

## v2.2
- Автонажатие кнопки подключения по умолчанию выключено: у Browsec она без подписи.
- Добавлена настройка «Перезапуск VPN без туннеля».

## v2.1
- Запуск без окна UAC через задачу Планировщика и автозапуск при входе в Windows.
- Имя процесса определяется по пути к .exe.
- Туннель считается активным, только если интернет-трафик идёт через адаптер VPN.
- Повторный запуск показывает окно уже работающей копии.

## v2.0
- Исправлено: правила брандмауэра никогда не удалялись, и приложение оставалось без сети.
- Исправлено: приложение запускалось с правами администратора и потом не открывалось обычным ярлыком.
- Исправлено: обрыв туннеля не обнаруживался, пока VPN-программа запущена.
- Приложение не запускается и не может быть открыто без VPN.
- Сборка встроенным в Windows компилятором (`build.bat`), без установки .NET SDK.
