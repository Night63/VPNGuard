# VpnGuard v2.3

**VpnGuard** — программа для Windows. Она разрешает выбранному приложению (например, Telegram или торговому терминалу MetaTrader) работать **только пока включён VPN**.

- Если VPN-туннель оборвался, приложение **сразу закрывается** и теряет доступ в интернет.
- Когда туннель восстановился, приложение **запускается снова**.
- Пока VPN выключен, открыть приложение вручную не получится: VpnGuard тут же его закроет.

Программу писали и проверяли с **Browsec VPN**. Она подойдёт и для других VPN-программ, которые создают в Windows свой сетевой адаптер (WireGuard, OpenVPN, sing-box и т. п.).

## 1. Быстрый старт

**Что понадобится:** Windows 10 или 11 и установленная VPN-программа (например, Browsec). Больше ничего устанавливать не нужно.

### Шаг 1. Скачать проект
На странице репозитория нажать зелёную кнопку **Code → Download ZIP** и распаковать архив в любую папку, например `C:\Tools\VpnGuard`.

> Путь к папке может быть любым, в том числе с русскими буквами и пробелами.

### Шаг 2. Собрать программу
Дважды щёлкнуть по файлу **`build.bat`**. Через несколько секунд появится надпись `Готово: bin\VpnGuard.exe`.
В папке `bin` окажутся программа `VpnGuard.exe` и файл настроек `appsettings.json`.

### Шаг 3. Настроить VPN-программу
Для Browsec: открыть его настройки и включить два пункта:
- **«Автоподключение VPN»** — чтобы Browsec подключался сам сразу после запуска;
- **«Автоматическое восстановление подключения VPN»** — чтобы он сам переподключался после обрыва.

### Шаг 4. Первый запуск
1. Запустить `bin\VpnGuard.exe`.
2. Windows спросит разрешение на запуск с правами администратора, ответить **«Да»**. Это понадобится только один раз: дальше VpnGuard запускается без этого вопроса.
3. Нажать **«Настройки»** и проверить два пути:
   - **«Путь к VPN .exe»**: где лежит VPN-программа. Для Browsec обычно `C:\Users\ИМЯ\AppData\Local\Programs\browsec-desktop\Browsec.exe`;
   - **«Путь к .exe»** в разделе «Ваше приложение»: программа, которую нужно защищать. Для Telegram обычно `C:\Users\ИМЯ\AppData\Roaming\Telegram Desktop\Telegram.exe`.

   Кнопка **«...»** рядом с полем открывает обычное окно выбора файла.
4. Нажать **OK**, затем **«Выход»** и снова запустить `VpnGuard.exe`.

### Шаг 5. Проверить
| Действие | Что должно произойти |
|---|---|
| Включить VPN | Надпись **«VPN: ПОДКЛЮЧЁН ✔»** (зелёная), приложение запускается само. Через 10 секунд окно VpnGuard сворачивается в трей (значок со щитом возле часов) |
| Выключить VPN | Приложение закрывается за доли секунды, окно VpnGuard появляется поверх всех окон с красной надписью |
| Снова включить VPN | Приложение запускается снова, через 5 секунд VpnGuard опять уходит в трей |

Готово. По умолчанию VpnGuard будет запускаться сам при входе в Windows.

## 2. Как это работает

### Как VpnGuard понимает, что VPN включён
Два раза в секунду программа проверяет три вещи:

1. **Запущена ли VPN-программа** (процесс `Browsec`).
2. **Есть ли сетевой адаптер VPN.** Включённая VPN-программа создаёт в Windows виртуальный сетевой адаптер. У Browsec он называется `browbox-tun-…` и описан как `sing-tun Tunnel`. VpnGuard ищет адаптер по **ключевым словам** из настроек.
3. **Идёт ли интернет через этот адаптер.** Иногда адаптер остаётся включённым, хотя VPN уже отключён. Поэтому VpnGuard спрашивает у Windows, через какой адаптер сейчас уходит трафик в интернет. Если не через VPN, значит, туннеля нет.

Дополнительно отслеживается системный прокси Windows: некоторые VPN работают через него, а не через адаптер.

Мгновенную реакцию на обрыв обеспечивают уведомления Windows об изменении сети. Регулярная проверка дублирует их на случай, если уведомление не придёт.

### Что происходит при обрыве VPN
1. Защищаемое приложение **принудительно закрывается**.
2. В **брандмауэре Windows** создаётся правило, запрещающее этому приложению доступ к сети. Это страховка на случай, если приложение кто-то успеет открыть.
3. Если VPN-программа закрыта, VpnGuard запускает её снова.
4. Окно VpnGuard появляется поверх всех окон, в трее показывается уведомление.

### Что происходит при восстановлении VPN
1. Правило брандмауэра удаляется.
2. Приложение запускается снова, если его закрыл VpnGuard.
3. Через 5 секунд окно VpnGuard сворачивается в трей.

### Права администратора
Чтобы управлять брандмауэром Windows, VpnGuard нужны права администратора. При этом:
- защищаемое приложение запускается **без** прав администратора, как при обычном двойном щелчке. Иначе Windows мешает потом открыть его обычным ярлыком;
- если VPN-программа сама требует прав администратора (Browsec требует), VpnGuard запускает её от своего имени, и окно подтверждения Windows не появляется.

### Запуск без окна подтверждения Windows (UAC)
При первом запуске VpnGuard создаёт в **Планировщике заданий Windows** задачу `VpnGuard` с наивысшими правами. Когда программу потом открывают двойным щелчком, она просит Планировщик запустить её через эту задачу, и окно подтверждения не появляется. Эта же задача отвечает за автозапуск при входе в Windows.

### Безопасность при выходе
При нормальном выходе, при сбое и при каждом запуске VpnGuard удаляет свои правила из брандмауэра. Так приложение не останется без сети навсегда.

## 3. Сборка из исходников

### Способ 1. `build.bat` (проще всего)
В Windows 10/11 уже встроен компилятор C# из .NET Framework 4.x (`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`). Поэтому:

1. Дважды щёлкнуть по `build.bat`.
2. Готовая программа появится в `bin\VpnGuard.exe`.

`build.bat` **не перезаписывает** уже существующий `bin\appsettings.json`, поэтому настройки сохраняются при пересборке. Чтобы вернуть настройки по умолчанию, нужно удалить `bin\appsettings.json` и запустить `build.bat` ещё раз.

### Способ 2. Visual Studio / .NET SDK
В папке `src` лежит проект `VpnGuard.csproj` (цель — .NET Framework 4.8):
```
dotnet build src\VpnGuard.csproj -c Release
```
или открыть его в Visual Studio 2019/2022 и нажать **Сборка → Собрать решение**.

### Требования к коду
Исходники написаны на **C# 5**: так их понимает встроенный в Windows компилятор. Если что-то менять, нельзя использовать `$"строки"`, `?.`, `=>` у методов и свойств, `nameof`, `out var` и другие возможности C# 6 и новее, иначе `build.bat` перестанет собирать проект.

## 4. Описание настроек

Все настройки меняются в окне **«Настройки»** и сохраняются в файл `bin\appsettings.json`. Файл можно править и в Блокноте, когда программа закрыта. В путях можно использовать переменные Windows: `%LOCALAPPDATA%`, `%APPDATA%`, `%USERPROFILE%`.

Большинство изменений вступает в силу после перезапуска VpnGuard.

### Раздел «Ваш VPN»

| В окне настроек | В файле | По умолчанию | Что делает |
|---|---|---|---|
| Путь к VPN .exe | `VpnProcessPath` | Browsec | Где лежит VPN-программа. Нужен, чтобы запускать её, если она закрыта |
| Имя процесса (по пути) | `VpnProcessName` | `Browsec` | Определяется автоматически по имени файла из пути. Менять не нужно |
| Ожидание старта VPN, сек | `VpnStartupWaitSec` | `20` | Сколько секунд дать VPN-программе на запуск и подключение, прежде чем пробовать ещё раз |
| Как проверять туннель | `DetectionMode` | `auto` | `auto` — по адаптеру VPN или системному прокси (рекомендуется); `adapter` — только по адаптеру; `proxy` — только по прокси; `process` — только по запущенной программе (ненадёжно, туннель не проверяется) |
| Ключевые слова адаптера | `VpnAdapterKeywords` | `browbox,sing-tun,browsec,wintun,wireguard,tap-windows,openvpn` | Слова, по которым узнаётся адаптер VPN (ищутся в имени и описании, через запятую). Как подобрать для своего VPN — см. [раздел 5](#5-если-что-то-не-работает) |
| — | `RequireVpnRoute` | `true` | Считать VPN включённым, только если интернет действительно идёт через адаптер VPN |
| Кнопка «Подключить» в VPN | `ConnectButtonNames` | `Connect,Подключить,…` | Надписи кнопки подключения в окне VPN-программы (используется вместе со следующей галочкой) |
| Запускать VPN-программу, если она закрыта | `KeepVpnRunning` | вкл. | Если VPN-программу закрыли, VpnGuard запустит её снова |
| Нажимать кнопку подключения в VPN | `AutoConnectVpn` | **выкл.** | VpnGuard сам нажимает кнопку подключения в окне VPN-программы. **У Browsec кнопка — ползунок без подписи, поэтому для него вместо этого включается «Автоподключение» в настройках самого Browsec** |
| — | `AutoConnectRetrySec` | `20` | Как часто пытаться нажать кнопку подключения |
| Перезапуск VPN без туннеля, сек | `VpnRestartIfDownSec` | `0` (выкл.) | Если VPN-программа запущена, а туннеля нет дольше этого времени, VpnGuard перезапустит её, чтобы сработало её автоподключение. Учтите: тогда ручное отключение VPN тоже будет отменяться |
| Кнопка «Сетевые адаптеры...» | — | — | Показывает все адаптеры, системный прокси и адаптер, через который сейчас идёт интернет |
| Кнопка «Элементы окна VPN...» | — | — | Показывает надписи кнопок в окне VPN-программы (для настройки автонажатия) |

### Раздел «Ваше приложение»

| В окне настроек | В файле | По умолчанию | Что делает |
|---|---|---|---|
| Путь к .exe | `TargetProcessPath` | Telegram | Программа, которой разрешено работать только через VPN |
| Имя процесса (по пути) | `TargetProcessName` | авто | Определяется автоматически: для `terminal64.exe` это `terminal64`. Название из Диспетчера задач (например, «MetaTrader 5 Client Terminal») — **это не имя процесса** |
| Аргументы запуска | `TargetStartArgs` | пусто | Параметры командной строки для приложения, если нужны |
| Запускать при старте VpnGuard | `StartTargetOnLaunch` | вкл. | Запустить приложение, как только VPN включится после старта VpnGuard |
| Перезапускать после восстановления VPN | `AutoRestartTarget` | вкл. | Снова открыть приложение, которое VpnGuard закрыл из-за обрыва |

### Раздел «Защита»

| В окне настроек | В файле | По умолчанию | Что делает |
|---|---|---|---|
| Интервал опроса, мс | `PollIntervalMs` | `500` | Как часто проверять VPN (500 мс = 2 раза в секунду). Изменения сети, кроме того, ловятся мгновенно |
| Завершать приложение при обрыве VPN | `UseProcessKill` | вкл. | Главная защита: закрыть приложение при обрыве и не давать открыть его без VPN |
| Блокировать через Windows Firewall | `UseFirewallBlock` | вкл. | Страховка: на время обрыва запретить приложению доступ к сети |
| Запускать программы без прав администратора | `LaunchUnelevated` | вкл. | Запускать приложение и VPN-программу как обычный пользователь (рекомендуется оставить) |

### Раздел «Запуск и окно VpnGuard»

| В окне настроек | В файле | По умолчанию | Что делает |
|---|---|---|---|
| Запускать без окна подтверждения UAC | `NoUacLaunch` | вкл. | Создаёт задачу в Планировщике, чтобы при запуске не появлялся запрос прав администратора |
| Запускать при входе в Windows | `AutostartAtLogon` | вкл. | Автозапуск VpnGuard через 15 секунд после входа в Windows |
| После запуска приложения сворачивать в трей | `MinimizeToTray` | вкл. | Окно прячется в трей после запуска приложения |
| — | `TrayDelayFirstSec` | `10` | Через сколько секунд свернуть окно после первого запуска приложения |
| — | `TrayDelayAfterRestoreSec` | `5` | Через сколько секунд свернуть окно после перезапуска приложения (VPN восстановлен) |
| При обрыве VPN показывать окно поверх всех окон | `ShowOnVpnDrop` | вкл. | При обрыве окно VpnGuard открывается поверх всех окон и остаётся там, пока VPN не восстановится |
| — | `TaskSignature` | — | Служебное поле, менять не нужно |

### Кнопки главного окна
- **Настройки** — открыть окно настроек.
- **Пауза / Продолжить** — временно отключить контроль. Пока стоит пауза, приложение работает и без VPN.
- **Выход** — закрыть VpnGuard и снять блокировки.
- **Значок в трее**: двойной щелчок открывает окно, правая кнопка открывает меню «Открыть / Выход». Кнопка «Свернуть» тоже прячет окно в трей.

## 5. Если что-то не работает

Всё, что делает программа, записывается в файл **`bin\VpnGuard.log`**. Начинать поиск причины стоит с него.

**VPN включён, а VpnGuard пишет «ОТКЛЮЧЁН».**
Программа не узнала адаптер VPN. Как это исправить:
1. Выключить VPN, открыть «Настройки → Сетевые адаптеры...» и запомнить список.
2. Включить VPN и открыть список ещё раз.
3. Найти адаптер, который появился (статус `Up`). Строка «Интернет-трафик сейчас идёт через» тоже укажет на него.
4. Взять слово из его имени или описания и добавить в «Ключевые слова адаптера» через запятую.

**Приложение не закрывается при обрыве / надпись «Приложение: не запущено», хотя оно работает.**
Проверить «Путь к .exe» в разделе «Ваше приложение»: имя процесса берётся из него.

**Приложение осталось без интернета после аварийного закрытия VpnGuard.**
Запустить `cleanup_firewall.bat` правой кнопкой → «Запуск от имени администратора». Второй способ — просто снова запустить VpnGuard: он сам удаляет старые правила.

**При запуске всё равно появляется окно подтверждения Windows.**
Один раз запустить VpnGuard и ответить «Да»: программа создаст задачу в Планировщике. Если программу перенесли в другую папку, нужно запустить её из нового места: задача обновится сама.

**VPN-программа не подключается сама.**
Включить автоподключение в настройках самой VPN-программы. Для Browsec это «Автоподключение VPN» и «Автоматическое восстановление подключения VPN».

## 6. Удаление
1. В VpnGuard снять галочки «Запускать без окна подтверждения UAC» и «Запускать при входе в Windows», нажать OK. Задача в Планировщике удалится.
2. Нажать «Выход».
3. Удалить папку с программой.

```
VpnGuard/
├── build.bat               сборка программы (встроенным компилятором Windows)
├── cleanup_firewall.bat    аварийное удаление правил брандмауэра
├── README.md               это описание
├── CHANGELOG.md            история версий
└── src/
    ├── Program.cs           точка входа: один экземпляр, запуск через Планировщик
    ├── MainForm.cs          главное окно и вся логика реакции на VPN
    ├── SettingsForm.cs      окно настроек
    ├── Config.cs            настройки и файл appsettings.json
    ├── VpnMonitor.cs        проверка VPN: процесс, адаптер, маршрут, прокси
    ├── TargetController.cs  запуск и закрытие приложения и VPN-программы
    ├── FirewallBlocker.cs   правила Windows Firewall (через netsh)
    ├── ProcessLauncher.cs   запуск программ без прав администратора
    ├── TaskSetup.cs         задача Планировщика (без UAC, автозапуск)
    ├── BrowsecAutomation.cs автонажатие кнопки в окне VPN (Accessibility)
    ├── Logger.cs            журнал VpnGuard.log
    ├── AppInfo.cs           название и версия программы
    ├── app.manifest         манифест Windows
    ├── appsettings.json     настройки по умолчанию
    └── VpnGuard.csproj      проект для Visual Studio / dotnet
```
